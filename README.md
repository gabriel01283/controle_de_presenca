## Sobre o projeto

O **Controle de Frequencia** é um aplicativo desktop desenvolvido para facilitar o acompanhamento de presença e faltas durante o semestre.

A aplicação permite organizar semestres, cadastrar disciplinas, definir limites de faltas e registrar cada aula realizada.

Os dados são armazenados localmente em um arquivo JSON.
